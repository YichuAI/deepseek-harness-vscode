# The composer does more than it looks

`Enter` sends; `Shift+Enter` adds a line. The rest is in the shortcuts:

- **`/`** — Harness commands. Typing it opens the list, and what you pick is
  inserted rather than sent, so you can add arguments first.
- **`@`** — reference a file. The agent reads it itself; nothing is pasted into
  your prompt, so a large file costs you nothing but the pointer.
- **paste an image** — the picture is staged and handed over as an attachment.
- **📎** — attach files to the session, the same way.
- **`Steer`** — appears while a turn is running. Ticked, your next message is
  injected into the running turn instead of waiting behind it.

Send something with no workspace open and one is created for you at that
moment, along with the session. There is no "new project" step to find first.

The editor context menu has the same reach: **Add to Harness Chat**,
**Send Selection to Harness**, **Explain / Fix / Review** for a file, a
selection, or a change in the Source Control view.
