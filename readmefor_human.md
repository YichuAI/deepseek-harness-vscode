# DeepSeek Harness for VS Code — 部署与发布指南

## 编译部署

运行以下命令即可自动完成编译、打包 VSIX 并安装到 VS Code：

```
npm run deploy
```

安装完成后，在 VS Code 中按 `Ctrl + Shift + P`，输入 **Reload Window** 并执行，即可让新版本生效。
